# CSC 350 - Material

Study material for CSC 350, Software Development. The course builds a web application with HTML, CSS, JavaScript, PHP and MySQL, running on XAMPP, and ends with a term project: a site with registration, login, and pages that read and write a database.

> [!CAUTION]
> ## This is not a replacement for the lectures
> These notes are a study aid. They do not cover everything said in class, and reading them does not excuse you from attending.

> [!NOTE]
> Everything in this repository is optional. The practice material is not graded. Do it if you want extra practice.
