JavaScript Fundamentals

Sixteen exercises from arithmetic to a JSON parser, ordered from easiest to hardest. Do them in order.

Each exercise is one file of small functions in exercises/. Edit it, save, refresh this page, and read the test results at the bottom. Exercise 05 is different: there you write the tests as well.

  1. 01Numbers and arithmetic

    Return values, operators, remainder, rounding, Math helpers.

    edit exercises/01-numbers.js, results below

  2. 02Strings

    Length, indexing, case, slicing, joining, reversing, palindromes.

    edit exercises/02-strings.js, results below

  3. 03Conditionals

    if / else, comparison, combining conditions, grades, leap years, triangles.

    edit exercises/03-conditionals.js, results below

  4. 04Loops

    for and while, accumulating a result, factorial, primes, fibonacci.

    edit exercises/04-loops.js, results below

  5. 05Testbuilder

    Detect a credit card network from its number, and write the Mocha tests yourself. Teaches how tests are built before you rely on them everywhere else.

    edit exercises/05-testbuilder.js and tests/05-testbuilder.test.js, results below

  6. 06Arrays

    First, last, sum, min and max, filtering, building new arrays, dedupe, chunk, zip.

    edit exercises/06-arrays.js, results below

  7. 07Objects

    Reading and writing properties, keys and values, counting, grouping, nested lookups.

    edit exercises/07-objects.js, results below

  8. 08JavaScript Koans

    Fill in the blanks in small tests to learn what the language really does with arrays, functions, objects, mutability and inheritance.

    edit exercises/08-koans.js, results below

  9. 09Real-world data

    Users, products, orders and students: find, filter, total, discount without mutating, reports.

    edit exercises/09-real-data.js, results below

  10. 10Functions as values

    Passing and returning functions, closures, counters, your own map / filter / reduce, compose, memoize.

    edit exercises/10-functions.js, results below

  11. 11Bees: ES6 classes

    A family of bee classes with class, extends and super: Grub, Bee, HoneyMakerBee, ForagerBee, RetiredForagerBee.

    edit exercises/11-bees-es6-classes.js, results below

  12. 12Bees: pseudoclassical

    The same bees with constructor functions and prototypes, to see what class does underneath.

    edit exercises/12-bees-pseudoclassical.js, results below

  13. 13Challenges

    Anagrams, run-length encoding, caesar cipher, binary search, bubble sort, roman numerals, balanced brackets.

    edit exercises/13-challenges.js, results below

  14. 14DOM

    Creating elements, classes, lists, click and input events, a counter widget, a todo list. See your widgets working in the playground.

    edit exercises/14-dom.js, results below

  15. 15Recursion

    Forty prompts from factorial to merge sort and deep clone. Every function must call itself; the tests reject loops.

    edit exercises/15-recursion.js, results below

  16. 16Recursion on JSON and the DOM

    Find elements by class name by walking the DOM tree, then write JSON.stringify and JSON.parse from scratch.

    edit exercises/16-recursion-json-dom.js, results below
